# Place catalogue data

`geo-catalogue.json` is generated by `web/scripts/generate-geo-catalogue.mjs`
(`pnpm --filter @onholidai/web geo:catalogue`). It provides the country
quick-picks, IATA-coded airports and the fallback used by live place lookup.

- Settlements: [GeoNames](https://www.geonames.org/) `cities5000` dump, the 12
  most populous settlements per country that have an IANA timezone. Licensed
  under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); attribute
  GeoNames when this data is displayed or redistributed.
- Airports: [OurAirports](https://ourairports.com/data/) `airports.csv`, limited
  to large and medium airports with scheduled service and an IATA code. Public
  domain. OurAirports carries no timezone, so each airport uses the timezone of
  the nearest settlement in the same country.

The file is reference data, not supplier supply: it never carries prices,
availability or confirmation state.
