# Tasks: AI Trip Planning Agent

**Input**: Design documents from `specs/001-ai-trip-agent/`

**Prerequisites**: `plan.md`, `spec.md`, `research.md`, `data-model.md`, all five documents in `contracts/`, and `.specify/memory/constitution.md`.

**Tests**: Included because the specification explicitly requires regression scenarios, production pricing checks, booking tests, and keyboard/screen-reader journeys in SC-005 and SC-009–SC-012. Tests target observable behavior and deterministic external doubles. Write each story's tests first and demonstrate relevant failures before implementation; rerun them at its checkpoint.

**Organization**: Four story phases preserve the specification's priorities: US1 P1, US2 P1, US3 P2, US4 P3. Setup and foundation are shared; each story has an independently runnable fixture and acceptance gate.

## Format: `[ID] [P?] [Story] Description`

- Every executable task starts with a checkbox and sequential task ID.
- `[P]` identifies tasks that can run together within an explicitly stated dependency wave, touching different files. It never waives prerequisites.
- `[US1]`–`[US4]` appear only on story tasks.
- Paths are relative to the repository root. Named source files are to be created where absent.

## Path Conventions

- `web/`: Next.js browser/BFF, sole application database owner, domain services, and TypeScript Temporal workers.
- `agent/src/onholidai_agent/`: FastAPI/LangGraph, bounded context, research integrations, and typed proposals.
- `contracts/`: committed language-neutral and generated contracts; feature design contracts remain in `specs/001-ai-trip-agent/contracts/`.
- `infra/`: Compose, Temporal, and observability configuration.
- `web/tests/` and `agent/tests/`: behavioral, contract, integration, evaluation, and end-to-end evidence.
